# CineGraph

> A public AI collaboration mirror for CineGraph.

CineGraph is a long-term research operating system for cinema: a living knowledge architecture for cinema, culture, history, theory, and their interconnected worlds.

## Purpose of this repository

This repository is a controlled public context layer for external AI collaborators and other approved readers. It is **not** the private CineGraph core repository.

The public mirror exists so that an external AI can understand the project without access to private material or private conversations.

## Start here

1. Read `docs/onboarding/AI_ONBOARDING.md`.
2. Read `docs/collaboration/HUMAN_AI_COLLABORATION_PROTOCOL_v0.1.md`.
3. Read the Foundational Specification when deeper context is required.

## Core principles

- Knowledge First
- Structure Before Content
- Everything Is Connected
- Human + AI Collaboration
- Long-term Stability

## Current mission

The immediate project priority is to establish reliable collaboration infrastructure so humans and AI systems can understand the project, coordinate work, contribute research, and avoid duplicated effort.

## Important boundary

Do not assume that this public mirror contains the complete CineGraph repository. Private architecture, internal notes, credentials, personal information, unpublished research, and other restricted material are intentionally excluded.

## Public mirror status

The mirror is an evolving AI-facing context layer. Its contents may change as the private CineGraph core evolves.
