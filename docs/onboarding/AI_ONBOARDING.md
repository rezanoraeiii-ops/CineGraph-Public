# CineGraph — Public AI Onboarding

## Purpose

This document is the entry point for external AI collaborators joining CineGraph through the public mirror.

It is not a replacement for the Foundational Specification. Its purpose is to provide enough orientation to begin understanding the project without private chat context.

## What is CineGraph?

CineGraph is a long-term research operating system for cinema.

Its mission is to build a permanent research infrastructure for cinema and to create a living environment in which knowledge can be organized, connected, researched, interpreted, revised, and eventually published.

## Core principles

- Knowledge First
- Structure Before Content
- Everything Is Connected
- Human + AI Collaboration
- Long-term Stability

## System layers

The current Master Architecture identifies six broad layers:

1. Architecture
2. Ontology
3. Knowledge
4. Research
5. Publication
6. AI

These are conceptual layers; do not assume that every layer is fully implemented.

## Current state

The project is in an engineering-bootstrap / foundation phase. The immediate goal is collaborative infrastructure, not full implementation of the complete CineGraph vision.

## How to begin

1. Read this onboarding document.
2. Read `docs/collaboration/HUMAN_AI_COLLABORATION_PROTOCOL_v0.1.md`.
3. Read the Foundational Specification for deeper context.
4. Distinguish documented facts from assumptions.
5. Before proposing work, check the available task/context information in the public mirror.
6. Do not invent missing project facts.

## Collaboration principle

The repository is intended to become shared project memory. Important findings, decisions, and useful work should be expressed in durable project artifacts rather than remaining only inside a private conversation.

## Current test

External AI collaborators are being evaluated on whether they can independently understand the project from the public mirror and identify what context remains missing.

When context is insufficient, explicitly say so rather than filling gaps by assumption.
